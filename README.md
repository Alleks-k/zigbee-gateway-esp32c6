# ESP32-C6 Zigbee Gateway

Цей проєкт перетворює мікроконтролер **ESP32-C6** на повноцінний Zigbee-шлюз (Coordinator) з веб-інтерфейсом для керування пристроями. Завдяки вбудованому радіомодулю ESP32-C6, шлюз підтримує протокол Zigbee 3.0 та дозволяє керувати пристроями (наприклад, розумними лампочками або розетками) через локальну мережу.

## 🚀 Основні можливості

- **Zigbee Coordinator**: Робота в ролі координатора мережі Zigbee.
- **Веб-інтерфейс**: Керування мережею та пристроями через браузер.
- **mDNS**: Доступ до шлюзу за адресою `http://zigbee-gw.local` замість IP.
- **Автоматичне збереження**: Список підключених пристроїв зберігається в енергонезалежній пам'яті (NVS).
- **Керування пристроями**: Підтримка команд On/Off для Zigbee-пристроїв.
- **RCP Auto-update**: Автоматичне оновлення прошивки радіо-копроцесора (якщо активовано в налаштуваннях).
- **SPIFFS**: Зберігання веб-файлів (HTML/CSS/JS) безпосередньо у флеш-пам'яті пристрою.

## 🛠 Апаратне забезпечення

- **Мікроконтролер**: ESP32-C6 (рекомендовано DevKit).
- **Живлення**: через USB або зовнішнє 5V.

## 💻 Програмне забезпечення

- **Framework**: [ESP-IDF](https://github.com/espressif/esp-idf) версії 5.1 або новішої.
- **Компоненти**:
  - `esp-zboss-lib` (Zigbee stack)
  - `esp-zigbee-lib`
  - `esp_rcp_update`
  - `mdns`

## ⚙️ Налаштування та збірка

### 1. Клонування репозиторію
```bash
git clone https://github.com/Alleks-k/zigbee-gateway-esp32c6-v1.git
cd zigbee-gateway-esp32c6
```

### 2. Конфігурація Wi-Fi та Zigbee
Запустіть меню конфігурації:
```bash
idf.py menuconfig
```
Перейдіть до розділу **Example Connection Configuration** та вкажіть:
- **Wi-Fi SSID**
- **Wi-Fi Password**

Також у розділі **ESP Zigbee gateway rcp update** можна налаштувати піни для RCP (якщо використовується зовнішній модуль) або залишити стандартні для вбудованого радіо.

### 3. Збірка та прошивка
```bash
idf.py build
idf.py flash monitor
```

## 🌐 Використання

1. Після успішної прошивки та підключення до Wi-Fi, пристрій запустить mDNS.
2. Відкрийте браузер і перейдіть за адресою: **[http://zigbee-gw.local](http://zigbee-gw.local)**.
3. **Функції веб-інтерфейсу**:
   - **Status**: Перегляд PAN ID мережі, поточного каналу та короткої адреси шлюзу.
   - **Permit Join**: Відкриття мережі на 60 секунд для підключення нових пристроїв.
   - **Control**: Надсилання команд On/Off підключеним пристроям.

## 📂 Структура проєкту

- `main/` — основний код програми.
  - `esp_zigbee_gateway.c` — ініціалізація Zigbee стеку.
  - `web_server.c` — логіка HTTP сервера та API.
  - `wifi_init.c` — налаштування Wi-Fi з підтримкою співіснування (Coexistence) із Zigbee.
- `www/` — папка з файлами веб-інтерфейсу (index.html, style.css, script.js).
- `partitions.csv` — таблиця розділів пам'яті (включаючи розділ для SPIFFS).

## ⚠️ Важливі зауваження

- **Wi-Fi Coexistence**: ESP32-C6 використовує одну антену для Wi-Fi та Zigbee (2.4 GHz). У коді налаштовано `esp_wifi_set_ps(WIFI_PS_MIN_MODEM)` для забезпечення стабільної роботи обох протоколів.
- **Обмеження**: У поточної версії `MAX_DEVICES` встановлено на 10 пристроїв (можна змінити в `web_server.h`).
